# ValenHack LAB 🔐

### Laboratorio educativo de ciberseguridad y redes inalámbricas

## 📌 Descripción del proyecto

ValenHack LAB es un proyecto práctico de ciberseguridad que demuestra cómo funciona una red Wi-Fi de laboratorio y cómo un dispositivo puede conectarse a ella para acceder a una página web alojada localmente.

El laboratorio fue desarrollado utilizando Kali Linux, VMware Workstation y un adaptador Wi-Fi USB, con fines exclusivamente educativos.

## 🎯 Objetivos

* Configurar una red Wi-Fi de pruebas.
* Comprender la asignación de direcciones IP mediante DHCP.
* Alojar una página web en un servidor local.
* Comprobar la conectividad entre dispositivos.
* Identificar riesgos de seguridad al conectarse a redes inalámbricas desconocidas.

## 🛠️ Tecnologías utilizadas

* Kali Linux
* VMware Workstation
* Adaptador Wi-Fi D-Link DWA-131 Rev. E1
* hostapd
* dnsmasq
* Python
* HTML

## 🌐 Configuración del laboratorio

| Parámetro        | Valor                 |
| ---------------- | --------------------- |
| Nombre de la red | `ValenHack_LAB`       |
| Red local        | `192.168.50.0/24`     |
| IP del servidor  | `192.168.50.1`        |
| Página web       | `http://192.168.50.1` |

## 🧪 Resultados

Durante las pruebas se configuró el punto de acceso inalámbrico, se verificó la asignación de direcciones IP y se comprobó el acceso desde un dispositivo de prueba a la página web alojada en Kali Linux.

## 📄 Documentación

El repositorio incluye un manual con los pasos de configuración, comandos utilizados, archivos del laboratorio, errores encontrados y soluciones aplicadas.

## ⚠️ Uso responsable

Este proyecto está destinado únicamente a la educación y a las pruebas realizadas con equipos propios o con autorización.

**No introduzcas contraseñas reales ni información personal en los formularios de demostración.** La página utiliza HTTP y no cifra los datos enviados.
